# paper_code — public publication track

Clean, publication-track manuscripts and code that consume the installed
`privateassets` library. Public. No proprietary data and no LP-level results.

- `jfqa_matf_pme/` — JFQA methods paper. The multi-factor money-weighted PME
  estimator, three theorems, inference, and MSCI cohort empirics.
  Status: to draft.
- `faj_application/` — FAJ practitioner application. Manager-skill dispersion
  (Layer 2), manager and vintage selection, and SAA, on Preqin fund-level data.
  Status: to draft, gated on Preqin terms.

The precursor Oaktree manuscript is not here. It runs on proprietary LP data and
lives in the private `projects/` tree.
